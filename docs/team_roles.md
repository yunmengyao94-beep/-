# 易校圈 · 团队分工模板（Sprint 1）

> 用途：明确职责边界与交付物，避免「谁都能改、谁都不负责」。
> 使用方式：每个 Sprint 启动时复制本模板，把「负责人」列填成具体姓名，删除不适用行。

## 1. 角色与职责

| 角色          | 核心职责                                                 | 本 Sprint 交付物                               | 负责人 |
| ------------- | -------------------------------------------------------- | ---------------------------------------------- | ------ |
| **前端**      | 页面结构、交互与端侧能力（OCR、WebAuthn 调用、内容拦截） | `frontend/` 页面骨架、组件样式规范、接口联调   | 待定   |
| **后端**      | Mock 服务、接口契约、数据库脚本与业务规则落地            | `server/` Mock 接口、`sql/` 脚本、规则配置校验 | 待定   |
| **测试**      | 用例设计、接口/页面验收、缺陷跟踪                        | 测试用例清单、冒烟脚本、验收报告               | 待定   |
| **项目/架构** | 技术决策、规范门禁、跨端契约仲裁                         | 目录规范、ESLint/Prettier 规则、评审记录       | 待定   |

## 2. 职责矩阵（RACI）

| 事项                             | 前端    | 后端    | 测试    | 架构    |
| -------------------------------- | ------- | ------- | ------- | ------- |
| 页面结构 / 样式实现              | **R/A** | C       | C       | I       |
| 接口契约定义（第七章）           | C       | **R**   | C       | **A**   |
| Mock 数据维护（`mock_api.json`） | C       | **R/A** | C       | I       |
| 数据库脚本（`sql/`）             | I       | **R/A** | C       | C       |
| 测试用例与回归                   | C       | C       | **R/A** | I       |
| 代码规范与提交门禁               | C       | C       | I       | **R/A** |
| 上线验收                         | C       | C       | **R**   | **A**   |

> R = 负责执行，A = 最终把关，C = 需被咨询，I = 需被知会。

## 3. 协作约定

1. **接口先行**：任何接口变更先改 `mock_api.json` 并在群里同步，前后端以该文件为唯一契约。
2. **分支模型**：`main` 保护分支；功能分支 `feat/<模块>-<简述>`，缺陷分支 `fix/<模块>-<简述>`。
3. **提交规范**：`feat|fix|docs|refactor|test|chore: <中文简述>`，一次提交只做一件事。
4. **门禁**：本地提交触发 `lint-staged`（ESLint + Prettier + `position: absolute` 扫描）；不通过不允许提交。
5. **跨端联调**：前端不得直连数据库或真实云服务，一律走 `server/` Mock；真实环境由后端在联调中期切换。
6. **缺陷流转**：测试提缺陷 → 对应角色修复 → 测试回归关闭；阻塞类缺陷 24 小时内响应。

## 4. 各角色完成定义（DoD）

- **前端**：页面在 Chrome / Safari / 移动端 WebView 均可用；无 `position: absolute` 布局；控制台无报错。
- **后端**：接口返回符合 7.2 统一响应结构；错误码与 7.2 错误码表一致；Mock 数据可复现。
- **测试**：核心链路（注册 → 发布 → 借用 → 交接 → 归还 → 定损）用例全部执行并留痕。
